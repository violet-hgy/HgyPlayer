# Design Measure

## 作用

只负责**读设计、量几何、量视觉参数、生成参数表**，不负责最终 QML 实现规则。

## 强制输出

改 QML 前至少输出：

- 【可视结构】
- 【像素参数表】
- 必要时【视觉参数表】

## Python 前置校验（门控）

在开始任何“像素测量 / 图像解析”前，必须确认运行环境满足 Python 依赖：

- 系统可执行 `python --version`
- 建议使用 Python 3.12+（版本过旧直接停止测量并提示升级）
- 能正确导入测量脚本依赖的图像库（至少应能 `python -c "from PIL import Image"` 成功）

若校验失败：

- 立即停止 `design-measure` 流程（不要用肉眼估值替代）
- 告知用户缺少的项（python 不存在 / 版本不满足 / PIL 导入失败）
- 等用户安装/修复后再重试测量

## 图片测量基本规则

- 先区分：整图边界 / 控件外框 / 内容区 / 文字墨迹 / 图标墨迹
- 给的图片，内部 UI 不一定完全填充图片，还是要以识图数据为主
- 禁止把导出留白或大画布直接当控件宽高
- 截图尺寸不等于设计 px；用户口头 px 优先级最高

## 几何参数必须覆盖

- 宽 / 高
- 左 / 右 / 上 / 下边距
- 相邻 gap / spacing
- 对齐轴 / 是否同宽 / 是否同轴
- 容器 padding
- 控件圆角

## 视觉参数必须覆盖

- 背景色 / 前景色
- 字号 / 字重
- 图标颜色 / 粗细
- 描边颜色 / 宽度
- 透明度
- 渐变 stop（能稳定读到时）

## 单控件切图

若是单个控件切图，且内部有明显单轴结构，必须尝试做“一维分段表”：

- 扫描线
- 连续像素段
- 每段对应的 UI 含义

## 阴影策略

- 识别到阴影目前先不做阴影不处理
- 只在【视觉参数表】或【差异 / 不确定】注明
- 禁止把阴影误判成描边

## 邻接联查

如果提供的是整页 / 整体布局图：

- 检查目标元素最近的上 / 下 / 左 / 右邻接控件
- 若同一布局链路有偏差，先列入【对齐过程发现的未对齐项】再改

## 禁止

- 未读图就写参数表
- 凭肉眼主观把估值写成“测量”
- 只量几何，不量颜色 / 字号 / 圆角 / 描边
- 把“位置差不多”当成“已对齐”
