# Design Visual Guard

## 作用

只负责**可视参数校验与门控**，确保不是“只把位置摆对”。

## 必查参数

- 背景色 / 前景色
- 字号 / 字重
- 圆角
- 描边颜色 / 宽度
- 图标颜色 / 粗细 / 朝向
- 透明度
- 渐变（能稳定读到时）

## 强制要求

- 根据图片生成或对齐 UI 时，不能只看几何
- 颜色、字号、字重、圆角等必须写进【视觉参数表】或并入【UI 参数表】
- 若某项无法稳定读到，明确写“未稳定读到”，不要猜

## 阴影

- 识别到阴影时，当前阶段只记录，不落地实现
- 阴影不等于描边

## 典型误判

- 把外阴影看成黑边框
- 把文字墨迹高度当字号
- 把图标导出画布当图标真实尺寸
- 只改 `spacing` / `margin`，保留默认颜色和圆角

## 禁止

- 用默认控件颜色冒充设计色
- 用统一圆角替代切图里不同控件的圆角
- 把“看起来像”当作已经对齐
